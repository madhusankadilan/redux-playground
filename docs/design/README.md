# Design

UI design for the todo app, the same in every app in this repo. The source is the Penpot file **Redux Playground**; these PNGs are exports of its boards.

## Design system

Colours (light and dark), typography, spacing, radius and components.

![Design system](design-system.png)

## Screens

Each state of the app in light and dark mode. The theme toggle in the header switches between them.

| State | Light | Dark |
|---|---|---|
| **Default**: three tasks, one done; hover on "Write tests" | ![Light default](light-default.png) | ![Dark default](dark-default.png) |
| **Typing**: input focused, Add enabled | ![Light typing](light-typing.png) | ![Dark typing](dark-typing.png) |
| **Filter Active**: only tasks that aren't done | ![Light filter active](light-filter-active.png) | ![Dark filter active](dark-filter-active.png) |
| **Loading**: tasks loading from the fake API | ![Light loading](light-loading.png) | ![Dark loading](dark-loading.png) |
| **Error**: loading failed, with Retry | ![Light error](light-error.png) | ![Dark error](dark-error.png) |
| **Empty**: no tasks | ![Light empty](light-empty.png) | ![Dark empty](dark-empty.png) |
